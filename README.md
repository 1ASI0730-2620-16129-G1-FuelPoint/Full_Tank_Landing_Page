# FullTank Landing Page

Landing page de FullTank, producto de FuelPoint.

## Ejecución local

Abre `index.html` en un navegador o sirve esta carpeta con un servidor HTTP estático. No requiere compilación ni instalación de dependencias.

## Implementación inicial

Incluye navegación responsive, portada, vista ilustrativa del producto y selector de idioma inglés/español. Las secciones restantes conservan únicamente sus títulos y anclas. Los datos de la vista del producto son ilustrativos.

La implementación adapta la landing original de [PrimeFuel/FullTank_LandingPage](https://github.com/PrimeFuel/FullTank_LandingPage), revisión `1488792f324761a2c135cfcb44fcb842249d6d67`.
